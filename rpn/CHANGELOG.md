# Route Planner — บันทึกการเปลี่ยนแปลง

เลขเวอร์ชัน `MAJOR.MINOR.PATCH` (แสดงใต้โลโก้มุมซ้ายบน พร้อมวันที่ build)

- **MAJOR** — `0` = ช่วง Pre-Launch · ขึ้น `1` เมื่อไฟล์ส่งออกผ่าน DMS จริงและกระจายให้ทุกศูนย์ใช้งาน · ขึ้นอีกเมื่อโครงข้อมูล/ไฟล์เปลี่ยนจนของเดิมใช้ต่อไม่ได้
- **MINOR** — รอบส่งมอบที่**เปลี่ยนวิธีทำงาน**หรือเพิ่มความสามารถ (ชุดโน้ตที่ตกลงกันแล้วทำครบ)
- **PATCH** — แก้บั๊ก / ปรับข้อความ / ปรับหน้าตา ไม่เปลี่ยนวิธีทำงานและรูปแบบไฟล์
