# Route Planner — โหมด Local

เวอร์ชันที่รันในเครื่องตัวเอง ไม่ต้องมีเซิร์ฟเวอร์ ไม่ต้องล็อกอิน ข้อมูลทั้งหมดเก็บอยู่ในเครื่องนี้เท่านั้น
เหลือไว้ 2 ฟังก์ชันตามที่ต้องการ คือ **วิเคราะห์สายวิ่ง** และ **วางแผนคิวงาน**

---

## วิธีเปิดใช้งาน

ดับเบิลคลิก **`Start-RoutePlanner.bat`** — จะเปิดเบราว์เซอร์ให้เอง ไม่ต้องใส่รหัสศูนย์แล้ว

หรือจะดับเบิลคลิก `RoutePlannerV0.html` ตรงๆ ก็ได้ ทดสอบบน Chrome แล้วใช้งานได้ครบทุกอย่าง
รวมถึงการเก็บข้อมูลถาวรด้วย (แนะนำ Chrome หรือ Edge — Firefox ไม่ยอมให้เก็บข้อมูลถาวรเมื่อเปิดไฟล์ตรงๆ
ระบบจะสลับไปใช้ที่เก็บสำรองซึ่งจำกัดราว 5 MB ให้อัตโนมัติ)

ไฟล์ `.bat` จะเปิดเซิร์ฟเวอร์เล็กๆ ในเครื่องให้ถ้ามี Python หรือ Node.js (ยังเป็น local 100% ไม่ได้อัปขึ้นเน็ต)
เป็นวิธีที่ปลอดภัยที่สุดเรื่องพื้นที่เก็บข้อมูล ถ้าไม่มีทั้งสองอย่างก็จะเปิดไฟล์ตรงๆ ให้แทน

> **ต้องต่ออินเทอร์เน็ตไหม?** ไม่ต้อง แผนที่พื้นหลังเป็นไฟล์ในโฟลเดอร์นี้เอง (ทั้งประเทศไทย)
> ไลบรารีทุกตัวก็เก็บไว้ในโฟลเดอร์ `vendor` แล้ว ระบบจึงทำงานได้ครบแม้ไม่มีเน็ต

### ศูนย์ (Distributor)

ไฟล์ชุดนี้ใช้ได้กับทุกศูนย์ ไม่ต้องแก้ URL หรือใส่เลขศูนย์ตอนเปิด

- นำเข้าไฟล์ RoutePlan ครั้งแรก ระบบ**ตั้งเลขศูนย์ให้เองจากคอลัมน์ `Distributor Code`**
- ถ้าไฟล์ที่นำเข้าเป็นคนละศูนย์กับที่เปิดอยู่ ระบบ**ถามก่อนเสมอ** ว่าจะย้ายไปศูนย์นั้นไหม
- ข้อมูลของแต่ละศูนย์เก็บแยกช่องกันในเครื่องเดียวกัน สลับไปมาได้ ข้อมูลไม่หาย
- สลับศูนย์: กด**ป้ายเลขศูนย์มุมซ้ายล่าง** (🏢 ...) จะมีรายชื่อศูนย์ที่มีข้อมูลอยู่ในเครื่องนี้
- ถ้า Restore ไฟล์ .json ของศูนย์อื่นเข้ามา ระบบสลับให้อัตโนมัติเมื่อช่องที่เปิดอยู่ยังว่าง

## เริ่มต้นใช้งาน

### 1. นำเข้าข้อมูล — ใช้ปุ่ม `📥 นำเข้าจากไฟล์ระบบ` เป็นทางหลัก

ใส่ 2 ไฟล์ที่โหลดออกจากระบบ AS&D ไม่ต้องแก้อะไรก่อน

| ไฟล์ | ระบบเอาไปใช้ |
|---|---|
| `MST - RoutePlan Detail` | สายวิ่งจาก `Route Code` · วันในรอบจาก `Cycle Name` · `Cycle Code` · ลำดับคิว (จากลำดับแถวใน CY เดียวกัน) |
| `MST - Customer Master` | พิกัด · ตำบล/อำเภอ/จังหวัด · ประเภทร้าน · **สถานะ Active/InActive** |

จับคู่ด้วย `Customer Code` — ในหน้าต่างนำเข้าเลือกได้ว่า

- **เดือนไหนบ้าง** — ไฟล์ RoutePlan ของ AS&D มีเดือนละแท็บ ระบบอ่านครบทุกแท็บและอ่านเดือนจาก `Visit Date`
  ค่าเริ่มต้นติ๊ก**เดือนล่าสุดเดือนเดียว** (แต่ละเดือนใช้เวลาราวครึ่งนาที เลือกหลายเดือนจะเตือนก่อน)
- **สายไหนบ้าง** — ค่าเริ่มต้นทุกสาย
- **สถานะร้าน** — ค่าเริ่มต้น *เฉพาะ Active*
- **ร้าน Active ที่ยังไม่อยู่ในแผน** — **ติ๊กไว้เป็นค่าเริ่มต้น** เอาเข้ามาไว้ในสาย `รอจัดสาย`
  แสดงเป็น**วงกลมกลวงขอบประสีแดง** บนแผนที่ = ร้านใหม่ที่รอจัด
  ย้ายเข้าสายจริงได้โดยคลิกที่หมุดแล้วเลือก `ย้ายไปสาย` หรือเลือกหลายร้านแล้วใช้ **แบ่งกลุ่ม → Assign ใหม่** ในแท็บ 2

> **Salesman Code ช่วยจัดให้ได้เกือบหมด** — ไฟล์ Customer Master มีคอลัมน์ `Salesman Code`
> ซึ่งใช้รหัสชุดเดียวกับ `Route Code` (ตรวจกับข้อมูลจริงศูนย์ 202: ตรงกัน 8,253 จาก 8,253 แถว)
> ระบบจึงขึ้นข้อเสนอให้ — บนหมุดจะเห็นบรรทัด `Salesman Code ในไฟล์ Master = 202V10` พร้อมปุ่มย้ายทีละร้าน
> และในแท็บ `1. ร้านค้า` มีแถบเหลืองปุ่ม **ย้ายเข้าสายตาม Salesman Code** ย้ายทีเดียวทั้งชุด
> (บอกก่อนว่าจะเข้าสายไหนกี่ร้าน · ร้านที่ย้ายแล้วยัง**ไม่ได้จัดวัน** ต้องจัดวันต่อเอง
>  ร้านที่ไม่มีรหัสหรือรหัสชี้ไปสายที่ไม่มีในระบบ จะคาไว้ที่ `รอจัดสาย` เหมือนเดิม)

> ร้านเดิมที่หายไปจากไฟล์ใหม่ จะถูก**พักไว้** (ซ่อนจากแผนที่แต่ไม่ลบ) และรายงานจำนวนให้ทราบ

### 1.0b ย้อนกลับ (Undo / Redo)

ปุ่ม `↶` `↷` อยู่บนแถบเครื่องมือถัดจากช่องเลือกสาย (หรือ `Ctrl+Z` / `Ctrl+Y`)
ย้อนได้ทุกการแก้ที่กระทบข้อมูล — เปลี่ยนวัน · ย้ายสาย · จัดลงวัน · Unassign · แบ่งกลุ่ม · AI จัดวัน · จัดลำดับคิว · สร้างสายใหม่ทั้งศูนย์ · ลบร้าน
เก็บ 20 ขั้นล่าสุด **ประวัติเริ่มใหม่ทุกครั้งที่เปิดหน้าจอใหม่หรือสลับเดือน** งานใหญ่ควรกด 💾 Save เก็บไฟล์ไว้ก่อน

### 1.0c จัดกลุ่มตลาด · สลับลำดับ · แบ่งกลุ่มร้านที่เลือก

- **แท็บ 1 จัดกลุ่มตามตลาด** — พับไว้ เห็นชื่อตลาด วันที่จริง จำนวนร้าน กดกางดูรายร้าน
  กลุ่มที่เคยอยู่วันอื่นจะติดป้ายส้ม `เดิม D3`
- **⇅ จัดลำดับตลาด** (ใต้ช่องค้นหา) — ลากสลับลำดับตลาดในสาย เช่น 1-2-3 → 1-3-2
  สลับทั้งกลุ่ม (ร้าน + ลำดับคิว + ชื่อตลาด) **CY ไม่ขยับเพราะผูกกับช่องวัน** สายที่มีร้าน F2 สลับครึ่งแรก ครึ่งหลังตามอัตโนมัติ
- **✂️ แบ่งกลุ่มร้านที่เลือก** (แท็บ 2) — วาดพื้นที่เลือกร้าน แล้วให้ระบบแบ่งเป็น N ก้อน
  บอกก่อนว่าร้านมาจากสาย/วันไหนบ้าง เลือกได้ว่าอิงสายเดิมหรือ Assign ใหม่ เสนอผลพร้อมสีบนแผนที่ก่อนกดรับ
  **กดคำนวณซ้ำได้ผลใหม่** (เปลี่ยนวิธีตัด: แน่นสุด → ตะวันออก-ตะวันตก → เหนือ-ใต้ → ทแยง → รอบศูนย์กลาง) และกดรับแล้วมี**สรุปก่อนยืนยัน**
  ว่าย้ายกี่ร้าน จากไหนไปไหน เรียงคิวใหม่กี่วัน — ย้อนกลับได้ด้วย Ctrl+Z
- **⛔ Unassign** (แถบจัดลงวัน แท็บ 2) — ทำกับ**ร้านที่เลือกเท่านั้น** เลือกระดับได้
  *ถอดวัน* = ล้าง Day/คิว/CY ร้านยังอยู่สายเดิม · *ถอดออกจากสาย* = ย้ายไปกอง `รอจัดสาย` ด้วย
  ส่วน **ล้างวันทั้งสาย** อยู่ท้ายแท็บ 4 (ทำเฉพาะสายที่กำลังแก้ ไม่แตะสายอื่นที่เปิดอยู่)
- **วาดเลือกพื้นที่เคารพตัวกรอง** — เปิดกรองวันเดียวไว้ วาดแล้วจะได้เฉพาะหมุดที่แสดง ร้านที่ซ่อนอยู่ไม่ติดมา (บอกจำนวนที่ข้าม)
- **ป้ายวันบอกวันที่จริง** — `วันที่ 18 (22 ต.ค.)` ถ้ายังไม่ตั้งปฏิทินจะขึ้นวันที่ของเดือนนั้นแบบสีจาง

### 1.0d หน้าตั้งค่าปฏิทิน

- เหลือโหมดเดียว **หมุนนับต่อเนื่อง** (นับเฉพาะวันทำงาน ข้ามวันหยุดให้เอง) — โหมด "วันที่ = Day" เอาออกแล้ว
- **Total Working Day** ใต้ช่องจำนวนวัน Cycle บอกวันทำงานจริงทั้งเดือนหลังหักวันหยุด · ใช้ไปกี่วัน · เหลือกี่วัน
  ถ้าตั้ง Cycle มากกว่าวันทำงานที่มีจริง จะขึ้นเตือนสีแดง
- **ตั้งค่าสำหรับ** มี 2 ปุ่ม: ทั้งศูนย์ / เลือกเฉพาะสาย — แบบเลือกเฉพาะสาย **ติ๊กได้หลายสายพร้อมกัน** บันทึกทีเดียวครบ
  สายที่ตั้งค่าแล้วมีป้าย `✓ ตั้งค่าแล้ว` และปุ่ม `แก้ไข`
- **กด "+ เพิ่มเดือน" แล้วหน้านี้เปิดให้เอง** (V0.6) — ตั้ง D1 = วันที่ 1 ไว้ให้ (ตรงวันหยุดประจำสัปดาห์เลื่อนไปวันทำงานแรก) · วันหยุดเฉพาะกิจไม่ติดมาจากเดือนเก่า ต้องใส่ของเดือนนั้นแล้วกดบันทึก

### 1.0e วันหยุดกับวันท้ายเดือน

- ครบรอบแล้วเดือนยังไม่หมด ระบบ**วนกลับไป D1 D2 D3 ต่อ**ให้เอง ไม่ปล่อยว่าง — ถ้าไม่ต้องการให้วันนั้นมีแผน ให้ตั้งเป็นวันหยุด
  สายรอบยาว (> 14 วัน) หน้าตั้งค่าขึ้นเตือนวันที่วนกลับ (ตลาดวิ่ง 2 ครั้ง) พร้อมปุ่ม **ตั้งวันที่ … เป็นวันหยุด (ไม่มีแผน)**
- **วันหยุดประจำสัปดาห์** (เสาร์/อาทิตย์) ระบบข้ามให้เสมอ ไม่กินตลาดของใคร
- **วันหยุดเฉพาะกิจ** (นักขัตฤกษ์/วันลา) เลือกได้ว่าจะให้ทำยังไง
  - **⟳ เลื่อนตลาดไปวันถัดไป** (ค่าเดิม) — ไม่มีตลาดหาย แต่ตลาดหลังวันหยุดเลื่อนตามกันทั้งแถว
  - **⤳ ตรึงตลาดไว้กับวันที่** — ตลาดอื่นไม่ขยับ ตลาดที่ตรงวันหยุดพอดีเดือนนี้ไม่ได้วิ่ง
  - **ศูนย์รอบสั้น (≤ 14 วัน) ค่าเริ่มต้น = ตรึง** (V0.7.3) — ไม่เกิดตลาดชนกับ "+14 วัน" · เดือนที่นำเข้าจากไฟล์ยังเป็น "เลื่อน" เพื่อให้วันที่ตรงกับไฟล์ · เปลี่ยนเองได้ทุกเดือน

### 1.0f ปุ่มที่เพิ่มเข้ามาใหม่

- **✖️ ยกเลิกเลือก** อยู่บนแผนที่ใต้ปุ่ม "วาดเลือกพื้นที่" โผล่เมื่อมีร้านถูกเลือก บอกจำนวนด้วย
- **🚩 / 🏁 บนหัวกลุ่มตลาด** (แท็บ 1) — ตั้งจุดเริ่ม/จุดจบของวันนั้นได้จากหน้ารายชื่อเลย ไม่ต้องเข้าหน้าต่างรายวัน
  ปุ่มเป็นสีเขียวถ้าตั้งไว้แล้ว
- **แท็บ 2 เรียงใหม่** — แถบ *จัดลงวัน* อยู่บนสุด ตามด้วยกล่องแบ่งกลุ่ม · **AI Route Builder ย้ายไปแท็บ 4** เพราะมันทำกับ*ทั้งสาย* ไม่เกี่ยวกับร้านที่เลือก
  ช่อง "ความยาวรอบ" ของ AI ล็อกตามปฏิทินสาย แก้ไม่ได้ (เดิมแก้แล้วไปทับความยาวรอบของศูนย์)
- **หน้าภาพรวมแผน (เมนูซ้าย ล่างสุด)** — มี dropdown เลือกเดือนบนหัว สลับแล้วทั้งแอปเปลี่ยนตาม · วาดใหม่เองเมื่อเดือนเปลี่ยน
- **หน้าภาพรวมแผน (V0.7.2)**
  - ช่อง "ดู" ติ๊กเลือกได้หลายสาย (ไม่เลือก = ทุกสาย) — การ์ด ปฏิทิน ตาราง รายการต้องแก้ คิดเฉพาะสายที่เลือก
  - การ์ด: ร้านค้าทั้งหมด · ร้านในแผน · รอจัดสาย · ครั้งเข้าเยี่ยม · F2 · **วันทำงาน** (วันในปฏิทินที่มีอย่างน้อย 1 สายเข้าเยี่ยม นับตรง ๆ ไม่เฉลี่ย)
  - ปฏิทิน: เลขวันที่มุมบนซ้าย · จำนวนร้านอยู่บรรทัดเดียวกับป้าย DX
  - ตารางรายสาย: Working Day (วันที่สายนั้นเข้าเยี่ยม) · Coverage · Visit · Re-Visit (ร้านถูกเข้า ≥ 2 ครั้ง) · ร้านค้าต่อวัน (Coverage ÷ Working Day) · แถว Grand Total
  - เทียบกับ**เดือนที่นำเข้าจากระบบล่าสุด** (แผนที่ DMS ใช้อยู่): Coverage เดือนนั้น · Diff · Increase/Decrease/Equal · **ย้ายเข้า** (เดิมอยู่สายอื่น/กองรอจัดสาย) · **ย้ายออก** (ไปสายอื่น) · **Remove** (ไม่อยู่สายไหนแล้ว/ปิดร้าน) · **ร้านใหม่** (ไม่มีในเดือนนั้นเลย แม้แต่กองรอจัดสาย)
    Diff = ย้ายเข้า − ย้ายออก − Remove + ร้านใหม่ · ระบบจดเดือนที่นำเข้าล่าสุดให้ตอนนำเข้า (เดือนเก่าใช้เดือนที่มาจากการนำเข้าก่อนเดือนที่ดูอยู่)
  รายการ *ต้องแก้ก่อนส่งออก* กดแล้วเปิดสายที่เกี่ยวและ**เลือกร้านชุดนั้นไว้ให้เลย** · มีกล่อง *ควรรู้ก่อนส่งออก* เตือนเดือนที่วันทำงานเกินความยาวรอบ
- **ปุ่มวันที่บนหัวตลาด** (เช่น `🔁 3 · 17 · 31 ต.ค.`) — โผล่เมื่อตลาดนั้นวิ่งได้มากกว่า 1 ครั้งในเดือน กดแล้วเปิดหน้าต่าง **ครั้งเข้าเยี่ยม** (ดูข้อ 1.7) ใช้แทนปุ่ม ×1/เดือน ⇄ เดิม
- **หน้าสรุป (แท็บ 3) ยุบไว้ก่อน** ทั้งการ์ดระยะ Master และการ์ดรายวัน กดหัวสายเพื่อกางทีละสาย
  หรือใช้ปุ่ม **⊞ กางทั้งหมด / ⊟ ยุบทั้งหมด**

### 1.1 จัดวันและลำดับคิว

- **จัดวัน** — แท็บ `2. จัดสาย` กด `เริ่มคำนวณ AI` หรือวาดพื้นที่เลือกร้านแล้วกด `จัดลงวัน`
- **ลำดับคิวในวัน** — แท็บ `3. สรุป` กด `🔢 จัดลำดับคิวทุกวันจากพิกัด`
  หรือคลิกการ์ดของวัน แล้ว**ลากสลับ / กดลูกศร**เพื่อแก้ทีละร้าน
  ร้านที่เพิ่งจัดลงวัน ระบบจะ**แทรกในตำแหน่งที่อ้อมน้อยที่สุด**ให้เอง

> ระยะที่ใช้จัดลำดับเป็น **ระยะถนนจริง** ถ้าโหลดตารางระยะถนนไว้แล้ว (ดูข้อ 1.2)
> ถ้ายังไม่ได้โหลด ระบบจะใช้ระยะเส้นตรงไปก่อนและบอกไว้ในกล่องระยะ Master
> (ทดสอบกับสายจริง 622 ร้าน 24 วัน: ระยะรวมลดจาก 3,604 กม. เหลือ 1,045 กม.)

### 1.2 ระยะ Master — ระยะมาตรฐานของแผน

อยู่ในแท็บ `3. สรุป` กล่องบนสุด บอกระยะของแต่ละวันและระยะรวมของสาย

หลักคิด: **เลือกกลุ่มร้าน → ระบบจัดลำดับเข้าเยี่ยมให้ → คำนวณระยะตามลำดับนั้น**
ตัวเลขที่ได้คือระยะมาตรฐานของแผนเดือนนั้น ใช้เทียบว่าสายไหนหนัก/เบา
และใช้เป็นฐานเทียบกับระยะที่วิ่งจริง — ถ้าวิ่งจริงห่างจาก Master มาก แปลว่าต้องกลับมาปรับ Route

ตัวเลขนี้จะถูก freeze ตอนกด Export และแนบไปในไฟล์เป็นชีท **`ระยะ Master`**
(สายวิ่ง · วัน · CY · ชื่อตลาด · จำนวนร้าน · ระยะ กม. · กม./ร้าน · จุดเริ่ม · จุดจบ)

> **ค่าเริ่มต้นคือระยะระหว่างร้านเท่านั้น** ระบบไม่เดาจุดตั้งต้นให้
> เพราะแต่ละศูนย์ทำงานไม่เหมือนกัน บางสายไม่ได้ออกจากที่เดิมและกลับที่เดิมทุกวัน
> ถ้าอยากได้ระยะรวมขาเดินทางด้วย ต้องระบุจุดเริ่ม/จุดจบเอง (ดูข้อ 1.3)

### 1.3 ชื่อตลาด · จุดเริ่ม · จุดจบ ของแต่ละวัน

คลิกการ์ดของวันในแท็บ `3. สรุป` (หรือคลิกแถวในกล่องระยะ Master) จะเห็นแถบบนสุดของหน้าต่าง

```
ชื่อตลาด  [ ในเมืองร้อยเอ็ด        ]
🚩 เริ่ม  —          🏁 จบ  —                    42.6 กม.
```

**ชื่อตลาด** — ตลาดที่นำเข้ามาจากไฟล์มีชื่อติดมาแล้ว แต่ถ้าจัดวันใหม่ที่ไม่เคยมี ต้องตั้งชื่อเอง
ไม่งั้นคอลัมน์ `Cycle route description` ในไฟล์ DMS จะไม่ครบ

**จุดเริ่ม / จุดจบ** — กดที่ `—` แล้วเลือกได้ 3 ทาง

| วิธี | เหมาะกับ |
|---|---|
| 📌 ใช้ร้านแรก/ร้านสุดท้ายของวัน | เร็วสุด ใช้ได้เลยเพราะมักพักแถวร้านสุดท้าย |
| 🗺️ ปักหมุดบนแผนที่ | รู้ตำแหน่งจริง ปักได้ตรงจุด (กด ESC ยกเลิก) |
| วางพิกัด / ลิงก์ Google Maps | มีพิกัดอยู่แล้ว วางลงไปได้เลย |

> **จุดจบของวันนี้ = จุดเริ่มของวันถัดไป** ระบบเติมให้อัตโนมัติ ไม่ต้องกรอกซ้ำ
> เช่นวันที่ 3 ไปจบที่ภูเวียงแล้วค้างคืน วันที่ 4 จะเริ่มจากภูเวียงเอง

**ปุ่ม `📍 จุดประจำสาย`** — ถ้าสายนั้นออกและกลับที่เดิมเป็นปกติ ตั้งจุดเดียวจบ
ทุกวันในสายจะใช้จุดนี้ ยกเว้นวันที่ระบุจุดเฉพาะไว้เอง — **ไม่ตั้งก็ได้**

**ปุ่ม `🛣️ ตารางระยะถนน`** — โหลดไฟล์ `road-matrix.bin` เข้าระบบ
โหลดครั้งเดียวแล้วระบบจำไว้ในเครื่อง ใช้งานต่อได้โดยไม่ต้องต่อเน็ต
(ถ้าเปิดผ่าน `Start-RoutePlanner.bat` และวางไฟล์ไว้ในโฟลเดอร์เดียวกัน ระบบจะโหลดเองอัตโนมัติ)

#### สร้าง/อัปเดตตารางระยะถนนเอง

ตารางระยะถนนสร้างจากข้อมูลถนนของ OpenStreetMap ล่วงหน้า ทำครั้งเดียวใช้ได้ตลอด
ต้องสร้างใหม่เมื่อ**มีร้านใหม่เข้ามาเยอะ** (ร้านที่ไม่มีในตารางจะถูกคิดเป็นเส้นตรงโดยประมาณ)

```
pip install osmium scipy numpy openpyxl
python3 tools/build-road-matrix.py \
        --pbf thailand-latest.osm.pbf \
        --master "MST - Customer Master.xlsx" \
        --out road-matrix.bin \
        --depot "คลังขอนแก่น,16.4322,102.8236"
```

- ไฟล์ `thailand-latest.osm.pbf` โหลดฟรีจาก https://download.geofabrik.de/asia/thailand.html
- `--depot` ใส่ซ้ำได้หลายจุด จุดที่ใส่ไว้จะได้ระยะถนนจริงของขาออก/ขากลับด้วย
- `--cache graph.npz` เก็บกราฟถนนไว้ รอบต่อไป (เช่น เพิ่มจุดตั้งต้น) จะเร็วขึ้นมาก
- ผลลัพธ์ราว 2 MB ต่อร้าน 7,600 ร้าน ใช้เวลาราว 11 นาที (รอบต่อไปที่มี cache ~6 นาที)

**ของศูนย์ 202 สร้างไว้ให้แล้ว** — ถนน 4.86 ล้านจุด · 225,288 กม. · ร้าน 7,594 + คลังขอนแก่น
ร้านทุกร้านเกาะถนนได้ (ห่างถนนกลาง 20 ม.) · ตัวคูณอ้อมที่วัดได้จริงของอีสาน = **1.199**

> ระยะที่ได้ถือว่าไป-กลับเท่ากัน (ไม่คิดถนนวันเวย์) ซึ่งในพื้นที่ต่างจังหวัดต่างกันน้อยมาก
> คู่ร้านที่ไกลกันเกินรัศมีที่เก็บไว้ (ค่าเริ่มต้น 25 กม.) จะใช้เส้นตรง × ตัวคูณที่**วัดได้จากตารางเดียวกัน**
> กล่องระยะ Master จะบอกด้วยว่าระยะกี่ % มาจากตารางถนนจริง (ของศูนย์ 202 อยู่ที่ 94%)

#### ถ้านำเข้าข้อมูลของศูนย์อื่น

ตารางระยะถนนผูกกับ **รหัสร้าน** ที่ใส่ไว้ตอนสร้าง ร้านของศูนย์อื่นที่ไม่อยู่ในตาราง
ระบบจะยังคำนวณให้ตามปกติ **แต่เปลี่ยนไปใช้เส้นตรง × ตัวคูณแทน** (ไม่ error ไม่พัง)
กล่องระยะ Master จะขึ้นเตือนเองเมื่อระยะที่ตรงกับตารางต่ำกว่า 60%

ทำให้ครอบคลุมทุกศูนย์ได้โดยใส่ `--master` ซ้ำหลายไฟล์ในคำสั่งเดียว แล้วได้ตารางเดียวใช้ร่วมกัน:

```
python3 tools/build-road-matrix.py --pbf thailand-latest.osm.pbf \
        --master "202 Customer Master.xlsx" --depot "คลังขอนแก่น,16.49101,102.88685" \
        --master "401 Customer Master.xlsx" --depot "คลังเชียงใหม่,18.79,98.99" \
        --out road-matrix.bin --cache graph.npz
```

- รหัสร้านซ้ำระหว่างไฟล์จะถูกตัดออกให้อัตโนมัติ
- ขนาดไฟล์โตตามจำนวนร้าน ราว 2 MB ต่อ 7,600 ร้าน
- จุดตั้งต้นแยกตามศูนย์ได้ ระบบเก็บจุดตั้งต้นแยกรายศูนย์อยู่แล้ว
- ถ้าศูนย์ใหม่อยู่นอกกรอบพื้นที่เดิม ต้องลบไฟล์ cache ทิ้งก่อน (จะอ่านแผนที่ใหม่ทั้งหมด)

### 1.35 ตัวกรองแผนที่ — สาย × วัน × ร้านใหม่

ช่องด้านซ้ายบนของแถบเครื่องมือ (ที่เดิมเป็นดรอปดาวน์เลือกสาย) กดแล้วเปิดแผงเดียวจบ

```
202C01 · 4 สาย · 1 วัน ▾
┌──────────────────────────────────────────────┐
│  [ทุกสาย] [สายเดียว]  │  [ทุกวัน] [ล้าง]      │
│  ☑ ● 202C01 ◀   48   │  ☑ ● วันที่ 1     32  │
│  ☑ ● 202C02     73   │  ☑ ● วันที่ 2     32  │
│  ☐ ● 202P02    302   │  ☑ ● วันที่ 3     27  │
├──────────────────────────────────────────────┤
│  ☑ ⊖ ยังไม่จัดวัน (ร้านใหม่)           267  │
│     [สีตามสาย]  สีตามวัน                     │
└──────────────────────────────────────────────┘
```

| ทำอะไร | ผลลัพธ์ |
|---|---|
| **ติ๊กช่องหน้าสาย** | สายนั้นโผล่บนแผนที่และในรายการ |
| **คลิกชื่อสาย** | ตั้งเป็น "สายที่กำลังแก้" |
| **ติ๊กวัน** | กรองว่าจะเห็นวันไหน — ข้ามทุกสายที่เปิดอยู่ |
| **ยังไม่จัดวัน** | เปิด/ปิดร้านที่ยังไม่มีวัน แยกจากตัวกรองอื่น |

ตัวเลขข้างหลังทุกบรรทัดคือจำนวนร้านที่ตรงเงื่อนไข อัปเดตตามที่ติ๊ก

**หน้าตาหมุดบนแผนที่**

| | |
|---|---|
| สายที่กำลังแก้ | หมุดเต็มมีเลขวัน กดแก้ได้ทุกอย่างเหมือนเดิม |
| สายอื่นที่เปิดไว้ | จุดกลมทึบ สีประจำสาย (หรือสีตามวัน) |
| **ร้านที่ยังไม่จัดวัน** | **วงกลมกลวงขอบประสีแดง** อยู่บนสุดเสมอ เห็นแล้วรู้ทันทีว่าคือร้านใหม่ที่รอจัด |

คลิกจุดของสายอื่น = แก้วันหรือย้ายสายได้เลย · Shift+คลิก = เลือกร้าน · ลากเลือกพื้นที่ก็เลือกข้ามสายได้

**รายการทางขวาแยกกลุ่มตาม สาย › วัน** พับเปิด-ปิดได้ หัวข้อสายใช้สีเดียวกับหมุด
กลุ่ม `⊕ ยังไม่จัดวัน` อยู่ท้ายสุดของแต่ละสายและกางไว้ให้เสมอ

> **ลำดับคิว · CY · การ์ดรายวัน · หน้าต่างรายวัน · ระยะ Master ทำกับสายที่กำลังแก้เท่านั้น**
> ออกแบบไว้แบบนี้เพื่อไม่ให้ลำดับคิวหรือ CY ปนข้ามสายเด็ดขาด
> ส่วนการเลือกร้านและจัดลงวันทำข้ามสายได้ — ร้านแต่ละตัวจะไปอยู่วันนั้น**ของสายตัวเอง**

เปิดครบ 16 สาย (~9,000 ร้าน) แผนที่ยังลื่น เพราะสายอื่นวาดเป็นจุดเบา ไม่ใช่หมุดเต็ม

> การสร้างสายวิ่งใหม่ที่ยังไม่มีในระบบ อยู่ที่แท็บ **4. สร้างสายใหม่** (AI จัดวันอัตโนมัติทั้งสายก็อยู่แท็บเดียวกัน)

- **เลข CY** — ออกใหม่ทั้งเดือนทุกครั้งที่ส่งออก = CY ล่าสุดของเดือนก่อนหน้า + 1 เรียง **สาย → วันเข้าเยี่ยม**
  (เช่น ก.ย. จบที่ CY0000016176 → ต.ค. เริ่ม CY0000016177) กดส่งออกซ้ำได้เลขเดิม · แก้เลขตัวแรกเองได้ถ้าไม่ตรงกับ DMS
  ระบบอ่าน "CY ล่าสุด" จากแผนเดือนก่อนที่อยู่ในเครื่อง (เดือนที่นำเข้าจาก Route Plan หรือที่ส่งออกไปแล้ว)

**Visit Frequency ไม่ต้องตั้งแล้ว** — ระบบตัดสินรายตลาดตามหลักในข้อ 1.7 (ช่องตั้งรายสายเดิมเอาออก)
ในหน้าต่างมีสรุปจำนวน CY แบบ 5 / แบบ 9 รายสายให้ดู

| ช่อง | CY แบบ 5 (Fortnightly) | CY แบบ 9 (Monthly) |
|---|---|---|
| G Visit Week | 1 / 2 = สัปดาห์คี่/คู่ **นับจากต้นปี** (สูตร Excel `WEEKNUM(วันที่,2)`) | 0 |
| H / I | Start date / End date | Start date / End date |
| J–P | `Y` ที่วันในสัปดาห์ของ Start date | `N` ทั้งหมด |
| R Visit Day of Month | วันที่ของ Start date | วันที่ของ Start date |

> `CUSTOMER_GEO_TREE` **ไม่ได้อยู่ในไฟล์นี้** เพราะเป็นข้อมูลที่ดึงลงมาจาก DMS
> (System & Admin Setup > Import/export Job) ไม่ใช่ของที่ระบบนี้สร้าง

### 1.5 ส่งออกไฟล์แผนไปแก้ใน Excel

หน้าวางแผนคิวงานเหลือปุ่มเดียวที่แถบล่าง: **`📝 แก้แผนใน Excel`** (ดูข้อ 1.6) · ไฟล์สำหรับอัปโหลดเข้า DMS อยู่หน้าภาพรวมแผน (ข้อ 1.4)
ระบบจะเติม `Cycle Code` ให้ตลาดที่ยังไม่มี โดยนับต่อจากเลขสูงสุดที่เคยเห็น (ไฟล์ DMS ออกเลขใหม่ทั้งเดือนตามข้อ 1.4)

> 1 CY = ร้าน + ลำดับคิว + วันเข้าเยี่ยม ที่ต้องเหมือนกันหมด · เลข run ต่อกันข้ามเดือนไม่รีเซ็ต
> ศูนย์รอบ 24 วัน: **ร้าน F2 อยู่คนละตลาด จึงมี CY คนละตัว** ระบบเก็บ CY แยกรายวันให้แล้ว

### 1.7 ครั้งเข้าเยี่ยมของตลาด และการแยก CY (V0.5)

**หลักการ (ตามที่ DMS อ่านไฟล์)**
- 1 CY = ร้าน + ลำดับคิว + วันเข้าเยี่ยม — ทุกครั้งใน CY ต้องเหมือนกันหมด
- ความถี่เป็นของ **ตลาด** (สาย × ช่องวัน) ไม่ใช่ของร้าน: `วิ่งทุกครั้ง (F2)` หรือ `วิ่งครั้งเดียว (F1)`
  ตอนนำเข้าตั้งตามคอลัมน์ Frequency ของไฟล์ (ค่าเดียวทั้งตลาด) · ตลาดที่ไม่มีค่า = วิ่งทุกครั้ง
- **สายรอบสั้น (รอบ ≤ 14 วัน เช่น 12 วัน)**: ครั้งถัดไป = ครั้งก่อน **+ 14 วัน** จนถึง End date
  (เดือนที่มี 5 สัปดาห์ได้ 3 ครั้ง เช่น 1 · 15 · 29) — ตรงกับที่ DMS ยิงซ้ำเองจาก Start date
- **สายรอบยาว (24 วัน)**: ใช้วันที่ตามปฏิทิน · ไม่เกิน End date

**ตอนส่งออก ระบบจัดเป็น CY ให้เอง**

| ครั้งที่ 1 / 2 / 3 | ผลลัพธ์ |
|---|---|
| เหมือนกันทั้งหมด | 1 CY แบบ 5 |
| ครั้งที่ 1 ต่าง, 2 = 3 | CY แบบ 9 (ครั้ง 1) + CY แบบ 5 เริ่มครั้ง 2 |
| 1 = 2 แต่ครั้งที่ 3 ต่าง / 1 = 3 แต่ 2 ต่าง / ต่างทั้งหมด | CY แบบ 9 ทุกครั้ง (ครั้งละ 1 CY) |

> End date ทุกแถวของสายเดียวกันเท่ากัน CY แบบ 5 จึงต้องวิ่งไปจนถึง End date · แตกเพิ่มตามจำนวนตลาดที่เปลี่ยน ไม่ใช่จำนวนเงื่อนไข
> "เปลี่ยน" = ครั้งในเดือนเดียวกันต่างกันเอง (ตัดร้านออกเท่ากันทุกครั้ง ยังเป็น CY เดียว)

**หน้าต่างครั้งเข้าเยี่ยม** — กดปุ่มวันที่บนหัวตลาด (แท็บ 1) หรือปุ่ม `🗓️ ครั้งเข้าเยี่ยม` ใน popup หมุด
- สลับ `วิ่งทุกครั้ง` / `วิ่งครั้งเดียว` (ตลาดแบบครั้งเดียวเลือกได้ว่าวิ่งครั้งไหน)
- **✂️ แก้ครั้งนี้** — แยกครั้งนั้นออกเป็นช่องวันใหม่ของสาย (รอบ 12 วัน: D3 ครั้งที่ 2 → วันที่ 15) ร้านและลำดับคัดลอกมา
  จากนั้นแก้ได้เหมือนช่องวันปกติ: ย้ายร้านเข้า/ออก จัดลำดับ **เปลี่ยนวันที่** (เช่น เลื่อนเป็นวันอังคาร)
  หัวกลุ่มของช่องนี้ในแท็บ 1 มีป้าย `✂️ D3·ครั้ง2 · 17 ต.ค.`
- **🔗 รวมกลับ** — ครั้งนั้นกลับไปใช้ร้านและลำดับของตลาดเดิม (ร้านที่อยู่เฉพาะครั้งนั้นกลับเป็น "ยังไม่จัดวัน")
- **➖ เอาร้านออกจากครั้งนี้** (V0.7.4) — ในหน้าต่างครั้งเข้าเยี่ยม แถวครั้งที่แยกไว้ เปิด "➖ เอาร้านออกจากครั้งนี้" → ติ๊กร้าน → `➖ เอาร้านที่ติ๊กออก` (หรือเลือกร้านในรายการ/แผนที่ แล้วกด `➖ เอาที่เลือกออก` บนหัวกลุ่ม) · ปุ่ม "ลำดับคิว" (เดิม "ดูร้าน") เปิดหน้าจัดลำดับของครั้งนั้น — ร้านหายจากครั้งนั้นอย่างเดียว ครั้งแรกและลำดับคิวเดิมไม่ถูกแตะ · ลำดับของครั้งนั้นไล่เลขใหม่ · เอาออกทุกร้านไม่ได้ (ใช้ "วิ่งครั้งเดียว" แทน)
  ถ้าแยกไว้แต่ไม่ได้แก้อะไร (ร้าน ลำดับ วันที่เหมือนเดิม) ตอนส่งออกระบบนับรวมเป็น CY เดียวให้เอง
- กล่องล่างบอกว่าตอนส่งออกตลาดนี้จะเป็นกี่ CY แบบไหน
- ยกยอดเดือนใหม่: ครั้งที่แยกไว้เป็นของเดือนเก่า ระบบรวมกลับให้ทั้งหมด

**ต้องแก้ก่อนส่งออก (หน้าภาพรวมแผน)**
- **ครั้งเข้าเยี่ยมตรงวันหยุด** — เช่น +14 ไปตกวันนักขัตฤกษ์ → เปิดตลาดนั้น กด "แก้ครั้งนี้" แล้วเลื่อนวัน
- **สายเดียววันเดียวมี 2 ตลาด** — มักเกิดเมื่อวันหยุดแบบ "เลื่อนตลาดไปวันถัดไป" ทำให้รอบแรกเลื่อน แต่ครั้งที่ 2 ยังเป็น +14
  แก้ได้ทั้งเปลี่ยนวิธีจัดการวันหยุดเป็น "ตรึงตลาดไว้กับวันที่" หรือแยกครั้งที่ชนแล้วเลื่อนวัน

### 1.8 ร้านย้ายเซลล์ — ไฟล์ GEO_TREE_END / GEO_TREE_START (V0.7)

DMS เก็บว่าร้านไหนผูกกับเซลล์คนไหนไว้ใน **Geo Tree** (ร้าน → Node ID) ย้ายร้านข้ามสายในแผนแล้วต้องอัป 2 ไฟล์ให้ DMS รู้ด้วย

1. นำเข้า 2 ไฟล์เหมือนเดิม แล้วจัดแผนตามปกติ
2. **ระบบตรวจให้เอง** — ร้านที่สายหลังจัด ≠ Salesman Code เดิม (จาก Customer Master ตอนนำเข้า) = ร้านย้ายเซลล์ (ไม่มี Salesman Code = ร้านใหม่)
   ถ้ามีและยังไม่ได้นำเข้า Geo Tree → ขึ้นเตือนในหน้าภาพรวมแผน ("ต้องแก้ก่อนส่งออก") และในหน้าต่างส่งออก · **ปุ่มส่งออก zip กดไม่ได้**จนกว่าจะนำเข้า
   ไม่มีร้านย้าย = ไม่ต้องนำเข้า Geo Tree
3. ดึงไฟล์ **CUSTOMER_GEO_TREE** จาก DMS (System & Admin Setup > Import/export Job) — ได้ไฟล์ .zip ทั้งบริษัท ไม่ต้องแตกไฟล์
   นำเข้าได้ 2 ที่: ช่องที่ 3 ในหน้า `นำเข้าจากไฟล์ระบบ` (ไม่บังคับ) หรือปุ่ม `📥 นำเข้า CUSTOMER_GEO_TREE` ในกล่อง **🌳 ร้านย้ายเซลล์** ของหน้าต่างส่งออก · ระบบเก็บเฉพาะศูนย์ที่เปิดอยู่ · นำเข้าไว้นานกว่า 30 วันขึ้นเตือน
4. กล่อง 🌳 บอกจำนวนร้าน **ย้ายเซลล์** และ **ร้านใหม่** ตาม Geo Tree · กด `📦 ส่งออกไฟล์ DMS (.zip)` ได้ GEO_TREE_END / START อยู่ใน zip
5. ส่งออกแล้วระบบเปลี่ยน Salesman Code ของร้านที่ย้ายเป็นสายใหม่ — เดือนถัดไปไม่เตือนซ้ำ

| ไฟล์ | ใส่ร้านไหน | Node ID | Start Date | End Date |
|---|---|---|---|---|
| GEO_TREE_END | เฉพาะร้านย้ายเซลล์ | Node เดิม | วันเริ่มผูกเดิม | วันก่อนเริ่มผูกใหม่ |
| GEO_TREE_START | ร้านย้ายเซลล์ + ร้านใหม่ | Node ของสายใหม่ | วันที่ 1 ของเดือนแผน (แก้ได้) | ว่าง |

- ร้านที่สายไม่เปลี่ยน**ไม่อยู่ในไฟล์** · ร้านในสาย "รอจัดสาย" และร้านที่พักไว้ (inactive) ไม่นับ
- Node ID = Node แม่ของศูนย์ (อ่านจากไฟล์ เช่น `BSTB06501D01`) + รหัสสายตัดเลขศูนย์ (`P06`)
- **สายที่ยังไม่มี Node ใน DMS** (เช่นสายใหม่ 501P16) ขึ้นเตือนสีแดง — ต้องสร้าง Node ใน DMS ก่อนอัป START
- ไฟล์รูปแบบเดียวกับที่ DMS ส่งออก: `.csv` ข้อความ UTF-16 คั่นด้วย Tab · วันที่ `ปปปป/ดด/วว`

### 1.6 แก้แผนใน Excel แล้วนำกลับเข้า (V0.9.3 · ปรับ V0.9.4)

ปุ่ม `📝 แก้แผนใน Excel` แถบล่างหน้าวางแผนคิวงาน → หน้าต่างมี 2 ขั้น
1. ① เลือก สายที่เปิดอยู่ / ทุกสาย / สายเดียว → `📤 Export เป็น Excel` — ได้ไฟล์ชีท **แผน**: 1 แถว = ร้าน × Day (ร้านที่เข้าหลาย Day มีหลายแถว · ร้านที่ยังไม่จัดวัน = Day ว่าง)
2. แก้ใน Excel ได้ 4 คอลัมน์ **สีเหลือง**: **สาย · Day · ลำดับ · ชื่อตลาด** · คอลัมน์ **สีเทา** ดูอย่างเดียว · ช่องสายมีรายการให้เลือก · ช่อง Day / ลำดับ กันพิมพ์เลขผิด
   - แก้เลข Day = ย้ายวัน · คัดลอกแถวแล้วแก้ Day = เพิ่ม Day · ลบแถว = เอาออกจาก Day นั้น (ลบทุกแถวของร้าน = ร้านไม่มีวัน)
   - แก้สาย = ย้ายร้านไปสายนั้น · ลำดับเว้นว่าง/เลขเดิม = ให้โปรแกรมแทรกจุดที่อ้อมน้อยสุดให้
3. กลับมาที่ปุ่ม `📝 แก้แผนใน Excel` → ② `📥 นำไฟล์ที่แก้แล้วกลับเข้า` → หน้าตรวจรายการ (เปลี่ยน Day / ย้ายสาย / ลำดับ / ถอดวัน / ชื่อตลาด / รหัสที่หาไม่เจอ) → `ใช้การเปลี่ยนแปลง`

## พื้นหลังแผนที่ (Esri) และคีย์แผนที่

มุมล่างซ้ายของแผนที่มีปุ่มสลับพื้นหลัง 3 แบบ **Light Gray** (เทาอ่อน ค่าเริ่มต้น หมุดเด่น) · **Main Road** (ถนน ชื่อถนน/ซอย) · **Satellite** (ดาวเทียม เช็คว่าพิกัดร้านตกที่อาคารจริงไหม) ทั้งสามแบบมาจาก Esri ต้องมี **คีย์แผนที่** (V0.6.1 เอาเมนู "อื่น ๆ" ออกแล้ว — พื้นหลังสำรอง OSM / ออฟไลน์ใช้เฉพาะตอนถอยอัตโนมัติ)

**ใส่คีย์ครั้งแรก** — เปิดไฟล์ `map-key.js` ในโฟลเดอร์นี้ด้วย Notepad วางคีย์ (ขึ้นต้น `AAPT…`) แทนข้อความ `PASTE_KEY_HERE` ให้อยู่ในเครื่องหมายคำพูดเดิม แล้วบันทึก → เปิดโปรแกรมใหม่ (หรือกดปุ่มพื้นหลังปุ่มไหนก็ได้ ระบบจะลองคีย์ใหม่ให้) ทุกเครื่องที่เปิดจากโฟลเดอร์ OneDrive เดียวกันจะได้คีย์นี้อัตโนมัติ

**คีย์หมดอายุ / เปลี่ยนบัญชี** — คีย์มีวันหมดอายุตามที่ตั้งไว้ในบัญชี ArcGIS Location Platform (location.arcgis.com → Developer credentials → รายการ RoutePlanner-V0 → Generate new key) ได้คีย์ใหม่แล้ววางทับใน `map-key.js` ไฟล์เดียว ไม่ต้อง build ไม่ต้องแก้ไฟล์อื่น

**ถ้าไม่มีคีย์ / คีย์ใช้ไม่ได้ / เครือข่ายบล็อก Esri** — โปรแกรมจะถอยไปใช้ OSM แล้วออฟไลน์เอง พร้อมข้อความบอกสาเหตุที่หัวแผนที่ ยังทำงานได้ตามปกติ แค่พื้นหลังต่างไป

**ทดลองเทียบพื้นหลัง** — เปิด `Basemap-Preview.html` (โฟลเดอร์เดียวกัน) จะเห็น 4 ช่องพร้อมกันพร้อมหมุดร้านของศูนย์ที่ใช้อยู่ และเวลาโหลดจริงจากเน็ตเครื่องนั้น วางคีย์ในช่องบนหน้าได้ (เก็บไว้เฉพาะเบราว์เซอร์นั้น)

## หน้าค้าง / เปิดไม่ขึ้น

1. ปิดแท็บ Route Planner ทุกแท็บ
2. เปิดไฟล์ **`Reset-RoutePlanner.html`** ในโฟลเดอร์เดียวกัน (หน้านี้ไม่โหลดข้อมูลแผน จึงไม่ค้างตาม)
3. กด **ก๊อปบันทึก** ส่งข้อความให้คนแก้ — จะเห็นว่ารอบก่อนค้างที่ขั้นไหน
4. กด **ดาวน์โหลดสำรอง** เก็บไว้ก่อน แล้วลอง **ล้างเฉพาะค่าชั่วคราว** → เปิดโปรแกรมใหม่
5. ถ้ายังไม่หาย ค่อยใช้ **ล้างทั้งหมด** แล้วนำเข้าไฟล์ RoutePlan + Customer Master ใหม่ (หรือ Restore จากไฟล์สำรอง)

โปรแกรมเองก็มีตัวจับจุดค้าง: ถ้ารอบก่อนปิดแบบผิดปกติ เปิดใหม่จะมีแถบดำล่างจอบอกขั้นสุดท้ายพร้อมปุ่มก๊อปบันทึก

## สำรองและย้ายข้อมูล

ข้อมูลอยู่ในเบราว์เซอร์ของเครื่องนี้เท่านั้น — **ล้าง browser data = ข้อมูลหาย**
ปุ่มอยู่มุมซ้ายล่าง:

| ปุ่ม | ใช้ทำอะไร |
|---|---|
| 💾 **สำรอง** | ดาวน์โหลดข้อมูลทั้งหมดเป็นไฟล์ `.json` — ควรทำทุกครั้งที่วางแผนเสร็จ |
| 📂 **กู้คืน** | โหลดไฟล์ `.json` กลับเข้าระบบ ใช้ย้ายข้อมูลข้ามเครื่องได้ |
| 🗑️ **ล้างข้อมูลทั้งหมด** | ลบแผนทุกเดือน สายวิ่ง ร้านค้า จุดเริ่ม-จุดจบ และยอดขาย ออกจากเครื่องนี้ |

**ปุ่มล้างข้อมูล** มีไว้เริ่มใหม่จากศูนย์ — ระบบนี้ไม่ได้ออกแบบให้เป็นที่เก็บข้อมูลถาวร
ล้างแล้วนำเข้า RoutePlan Detail + Customer Master ใหม่ได้ทันที (ไฟล์ RoutePlan มีข้อมูลหลายเดือนอยู่แล้ว)
ในหน้าต่างยืนยันมีปุ่มสำรองให้กดก่อนได้

> **ตารางระยะถนนไม่ถูกล้าง** เพราะเป็นตารางอ้างอิงถนน ไม่ใช่ข้อมูลแผน
> ถ้าอยากเปลี่ยนตาราง ใช้ปุ่ม `🛣️ ตารางระยะถนน` เลือกไฟล์ใหม่ทับได้เลย ไม่ต้องล้างก่อน

### เลขศูนย์ที่แสดงในระบบ

ป้าย 🏢 มุมซ้ายล่างและบนหัวจอ คือ **Distributor Code ที่อ่านจากไฟล์ RoutePlan Detail** ที่นำเข้า
ไม่ได้มาจาก URL — เปิดด้วย `Start-RoutePlanner.bat` หรือเปิดไฟล์ตรงๆ ก็ได้เลขเดียวกัน
เลขนี้คือตัวที่ไปอยู่ในคอลัมน์ `Distributor Code` ของไฟล์ DMS ด้วย
ยังไม่ได้นำเข้าข้อมูลจะขึ้นว่า `— ยังไม่มีข้อมูล —`

**ใช้หลายเครื่อง:** เครื่องหนึ่งสำรองเป็นไฟล์ `.json` → ส่งไฟล์ไปอีกเครื่อง → กดกู้คืน
(ไม่มีการซิงก์อัตโนมัติ เพราะไม่มีเซิร์ฟเวอร์กลาง)

## สิ่งที่ต่างจากเวอร์ชันบนเว็บ

| หัวข้อ | เวอร์ชันนี้ |
|---|---|
| ที่เก็บข้อมูล | ในเครื่อง (IndexedDB) แทน Firebase |

| ใช้พร้อมกันหลายคน | ไม่ได้ ต่างเครื่องต่างข้อมูล |
| เมนู Dashboard / กระจายสินค้า / Audit Log / ภาพรวมทุกสาย | ตัดออกทั้งหน้าและโค้ด (dashboard.js 117 KB → เหลือ route-analysis.js 26 KB) |
| ปุ่ม LIVE / เช็คการยืนยัน / คำขอย้ายวัน / เปลี่ยนรหัสผ่าน | ตัดออก — เป็นงานคู่กับแอปฝั่งเซลซึ่งไม่มีในเวอร์ชันนี้ |
| PWA / ติดตั้งเป็นแอป | ตัดออก |
